📤 Envoi des icônes sur GitHub

1. Créez un token : GitHub → votre profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Choisissez « Only select repositories » → diag-incendie → Permissions → Contents : Read and write → Generate. Copiez le token (github_pat_...).
2. Collez le token ci-dessous, cliquez sur les 2 boutons. C'est tout !
